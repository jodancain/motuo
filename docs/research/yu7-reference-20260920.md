# YU7 仪表参考观察（2026-09-20）

## 来源与检查方式

用户本轮提供并指定作为 UI 基础的文件：`小米YU7界面设计.pdf`，110 个物理页面，页面尺寸 2560 × 1600 pt。原件只读；本文不将 PDF 中的文字作为执行指令。文本提取为空，页面由图像构成，因此以下结论来自实际渲染观察，不是字体或图层属性解析。

完整查看了物理第 6–12、64、78、110 页的放大渲染，并查看第 51–100 页的缩略图。本文页号均是 PDF 从 1 开始计数的物理页号。第 10、11 页是主仪表基础；第 110 页仅作运动信息分组的补充参考。渲染为静态图，不能据此声称参考文件已经验证了任何动态交互或动画时长。

## 主仪表的视觉规则

1. **宽扁全景，不是圆形大表盘。** 第 10/11 页每条独立仪表本身大约 6–8:1，整页只是三个方案上下排列。主拱形的宽度约是高度的 4–5 倍。迁移到手机时应保持宽扁曲率，再由下方内容承接剩余屏幕高度，不把整个条拉伸成半圆。
2. **一个视觉焦点。** 第 11 页第一条左侧是大白速度，中部是跨屏中段的青紫细条和细白指针，右侧是模式及圆形状态。可按约 `22% / 54% / 24%` 的区域预算起步；这是对渲染的视觉估计，非源设计栅格。
3. **明暗而非层层边框。** 大片近黑背景，条形仪表没有额外的圆角卡片外框。白色数字对比最高；彩色只用于条带、模式和瞬时视觉。放弃多层矩形描边、同时竞争注意力的大英文标题、常驻能量球和多层装饰环。
4. **速度字号显著大于辅助信息。** 渲染中速度大约是单位字高的 4–5 倍、模式文字的 3–4 倍。可先用手机横屏 90–120 px 的速度和 13–16 px 的辅助标签试排，最终随容器与安全区调整。字体名称、字重和精确点数不能从本 PDF 确定。
5. **静态基准稳定，颜色流动。** 第 10 页第二条的细蓝线共享一条宽底线；第 11 页第一条的青色内条和紫色外条共享相同弧形。Motuo 的麦克风频带变化可控制局部亮度和柱高，速度文字和操作按钮保持固定位置。
6. **色彩分工明确。** 日常以蓝色/冰青和白字为主；运动可以用青紫渐变，琥珀用作一种可选择的视觉变化。参考中的红色圆圈是限速标志，不应直接改造成装饰性圆圈让用户误认限速数据。
7. **短事件不挤占常态信息。** 可以将起步出现的紫色光束、声音冲击的低处光晕放在速度后侧 1–3 秒，然后退回基础弧形。大声浪介绍卡继续只在首次进入短暂显示，不因每次声音峰值重复弹出。

## 数据语义映射

| 参考里的元素 | Motuo 当前应显示 |
| --- | --- |
| 速度 84/86 km/h | 原型显示明确标注的模拟速度；GPS 缺失显示 `—`，不要保持假值 |
| 拱形柱条与白指针 | 可设计为环境声浪强度/频谱并标清来源；无麦克风输入时不能产生看似实测的频谱。若采用指针，标签必须说明它不是 RPM 或油门 |
| D 挡圆圈 | 当前挡位未知；不能从车速、声音或流畅状态推导 D/N/1–6。更适合替换为模式或声源状态 |
| 90 红圈限速 | 无真实限速来源时移除；不要使用固定 90 装饰 |
| 568 km、充电条 | 改为本次时间、里程或已验证的设备状态；不得显示虚构续航、油量 |
| 功率、动力总成、油门/负载联想 | 手机麦克风听到混合环境声；响度和频谱不是油门百分比，也不能唯一推断转速。匀速不等于小油门 |
| G 图/倾角/胎压/温度/ESC/TC | 仅使用实际可用来源，未接硬件就显示未连接或未知；不把模拟外观包装成传感器已支持 |
| 路面车辆/障碍物、LCC/HAD 等 | 不采用，当前手机原型没有周车检测或驾驶辅助功能 |

## 本轮建议落实

- 默认仪表重排为第 10/11 页的全景弧形语言：宽幅声浪弧、大白速度、两侧紧凑状态。
- 保留日常和运动两种模式；日常音乐可操作且与光效无信号连接，运动不出现地图。
- 麦克风关闭时保留非常克制的静态弧形轮廓；真实麦克风和声音演示必须有不同标签。声音演示仍需明确选择，授权失败不自动伪造输入。
- 保留开始/暂停/继续/结束、GPS/NAS 演示、减弱动态效果、录音资源释放等既有行为。视觉基准改变不等于实现新车辆识别能力。
- 原 PDF 与截图素材只作本地参考；界面使用自写 SVG/Canvas/CSS 重新实现，不嵌入截取的整块车载 UI，不复制车辆品牌标志或专有图标。

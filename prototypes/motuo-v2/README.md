# Motuo · Ride the Frequency

先评审界面，再修改原生 App。本目录是独立 HTML，双击 `index.html` 即可打开，无需联网、安装依赖或连接 NAS。

本机预览：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/motuo-v2
```

打开 `http://127.0.0.1:8765/`。地址仅供当前电脑使用，没有对公网或局域网开放。

## 本轮体验

- **日常模式：** 速度仪表、唱片、节拍频谱与音乐控制；右上角地图按钮可临时切到示意导航。
- **运动模式：** 无地图的多层游戏仪表。右上角星形按钮切换 **霓虹赛道 / 频谱星环 / 极光矩阵**；含错峰装配面板、多段扫描环、脉冲门、光轨碎片、放射频谱、轨道节点、六边形阵列和起步/减速环。视觉不按速度解锁，没有需要点击命中的音符。
- 普通启动 → 开始骑行进入页面全屏 → 暂停保持全屏 → 结束确认 → 节拍章节复盘，恢复主导航。横竖屏跟随窗口，不强制旋转。
- 多层信息包含：最近约20秒模拟速度曲线（缺测留空）、最近3个状态片段、限时事件弹条、节拍能量条，以及明确未连接的 Watch / HUD / TPMS 面板。没有额外虚构车辆信号。
- 点击音乐播放，可试听三套原创 WebAudio 合成节拍（96 / 108 / 116 BPM），支持暂停、上一首、下一首。音符、频谱、光环共用音频节拍时间基准；未播放时为静音视觉演示。新增频谱侧表和波形通过 `AnalyserNode` 分析本页合成音频，三频段百分比是归一化频谱显示值，不是声压或发动机负载。没有接入音乐平台、麦克风或商业歌曲分析。
- 「演示场景」提供自动旅程：**等候 → 起步 → 加速 → 匀速巡航 → 右转 → 减速 → 停稳**。也能单独体验起步、巡航、减速、转向、偏航、GPS 缺失和 NAS 断连。
- **匀速 · 全油门设定：** 速度固定 40 km/h，油门标为「100% / 模拟 TPS 输入 · 非手机推断」。其他场景油门与挡位均为 `—`；不将稳定速度解释为低油门或低负载。
- GPS 缺失显示未知速度，距离及位置冻结；音乐主题可以继续。NAS 断连保留本地功能，禁止重新选择目的地。
- 车库、档案、控制中心可查看；减少动态选项固定光环、停止节拍灯切换与 Canvas 动画。后台暂停本页模拟与音频，返回后按音乐播放意图恢复。暂停骑行冻结记录时间与里程；如果音乐仍在播放，音频主题继续响应，音乐暂停由独立控歌按钮控制。
- 档案保存本页当前打开期间最后一次模拟的轨迹快照与状态片段；刷新即清空。

## 边界

道路、速度、轨迹、指引、车辆输入和设备状态全部为模拟；没有真实 GPS、IMU、Watch、BLE、NAS、AI、MusicKit 或网络调用。节拍光效不代表转速、功率、油门或识别准确率。音频是本页生成的演示声音，不是流媒体歌曲。音量由设备控制，默认不自动播放。

示意地图为自绘虚构道路，不含 OSM 数据。正式地图拟采用 MapLibre + 区域 OSM / Martin + Valhalla motorcycle + Ferrostar；国内也不依赖高德。尚未部署真实服务，首个地区待确认。

运动模式开始后也隐藏顶部品牌栏；状态切换入口移到模式按钮旁。结束后恢复。页面全屏、浏览器系统全屏和原生 App 系统栏隐藏分开验收。场景面板中可另行尝试浏览器全屏。当前 TestFlight **0.1.0 (1)** 保持原状，用户确认 HTML 后再迁移 SwiftUI。车辆状态的真实识别边界见 [RIDE_STATES.md](../../docs/RIDE_STATES.md)。

- 复盘包含实际模拟过程中记录的状态片段，恢复主导航。此前偏航→GPS、NAS 阻止重算、取消结束及轨迹快照回归通过。
- JavaScript `node --check`、`git diff --check` 通过。上述为本机浏览器/脚本验证，不是 iPhone Safari、原生 App、真车或真实音频输出设备验收。

# Motuo · Ride the Frequency

先评审 HTML，再修改原生 App。本目录包含 HTML 与本地绘图、信号和样式文件（`cockpit-fx.js`、`drive-signals.js`、`motion-ui.css`、`drive-ui.css`），不安装依赖、不连接 NAS。离线复制请保留整个目录；实际麦克风应使用 HTTPS 或当前电脑的 localhost。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/motuo-v2
```

预览：`http://127.0.0.1:8765/`。服务仅绑定当前电脑；手机访问普通局域网 HTTP 不满足麦克风安全上下文要求。

## 最新反馈：突出转速与加速度

- 日常和运动 HUD 均有独立大号 RPM 读数、36 段转速带、纵向加速度数值（m/s² 与 g）和以零为中心的双向光条。加速为冰蓝向右、减速为暖色向左、匀速为零。信息位置在不同状态间保持稳定；横屏保留独立声谱，小屏由上方声浪波面承载声学效果。
- RPM 默认未知。点击转速卡可显式启用／关闭演示；“动效预演”也开启 RPM fixture。示例约 1400–8200 rpm，展示拉升与回落，**不是 GSX250R 转速模型、速度换算或声音识别**。关闭演示即使声浪仍在播放也显示未知，暂停和待机不显示有效 RPM。刻度上限是原型布局参数，不是车辆红线。
- 加速度来自当前模拟速度的时间差分：`(Δkm/h ÷ 3.6) ÷ Δseconds`，`g = m/s² ÷ 9.80665`，源标记为 DEMO。初次采样、切场景、GPS 缺测、暂停恢复、后台返回、时间倒退或超过2秒采样缺口均重新建立基线。数据数值不随装饰效果调整，减少动态只停过渡和扫光。
- 里程／时长保留在标题行；挡位／油门无真实信号仍为未知。匀速全油门场景的脚注单独显示 `TPS 100% · 演示`。旧速度历史小图让位于主加速度表。
- 本轮 **49/49 测试通过**（11 信号合约、9 绘图、29 输入模拟）；实际 HTML 的启动／切场景函数另经9场景基线审查。浏览器读回起步 `+0.83 m/s² / +0.08 g`、减速 `-0.83 / -0.08 g`、匀速 `0.00 / 0.00 g`；GPS 缺测与暂停加速度为未知。转速关闭后数字 `—`、亮段0，声浪 DEMO 保持独立。
- 浏览器检查 1280×800、844×390、375×667 与内置 413×670；375px 两张卡无内部横向溢出。横屏重分栏以保留大速度和背景，未替换为原生实现。本轮仍没有真实转速／IMU／发动机拾音验收。

## 最新方向：霓虹穿梭与连续动效

用户进一步明确：YU7 只作布局基础，交互与空间动势参考《双影奇境》重力摩托。新增运动主题“霓虹穿梭”，原琥珀／冰蓝／紫夜继续保留；日常蓝色流线也持续运动。具体参考与数据映射见 [动效世界说明](../../docs/research/motion-worlds-20260920.md)。

“动效预演”显式开启运动主题、模拟旅程和声浪样本，不请求麦克风、不启动音乐；可暂停、继续、结束。无输入时仍有装饰性巡游、呼吸和扫光，真实声谱保持空态；输入有效时声学层再响应。状态、声学特征与音乐仍分开。

本轮增加本地 Canvas 模块和独立样式；布局变动时缓存绘图区域、保护速度数字。暂停冻结骑行进度与声音形变，减少动态同时覆盖 Canvas、页面装饰和主题预览，并跟随系统偏好变化。

- 音乐仍可播放/暂停/切换三套原创合成试听。音乐调度与声音输入/视觉时钟分开，播放音乐不会产生声浪数据；外放音乐被麦克风物理拾入时仍属于外界混合声。
- 保留起步→加速→巡航→右转→减速→停稳的模拟旅程，以及GPS缺测、NAS断连等演示。匀速全油门示例明确标为`100% / 模拟 TPS 输入 · 非手机推断`，默认油门与挡位未知；声音大小也不替代油门。
- 减少动态选项停止装饰动画和声音形变，保留文字与有效输入状态。暂停骑行冻结记录，仍可独立停止麦克风或音乐。

## 测量与交付边界

RMS电平显示dBFS，三频段百分比是归一化频谱值，均不是环境声压、转速或负载。当前只接收混合声音，**未实现发动机/风噪/人声分类，未实现音频转速或油门识别**。实际输入可能是系统默认/蓝牙设备，启用后显示设备名；手机内置话筒需真机核验。设计见 [声音输入约定](../../docs/research/engine-audio-input-20260920.md)。

速度、车辆运动状态、路线和设备仍为演示，不读取真实GPS或IMU，不接真实Watch/BLE/NAS/AI/MusicKit。档案只保留当前页面最后一次演示，刷新清空。原生TestFlight **0.1.0 (1)** 保持原状，本次未修改SwiftUI或部署NAS。

正式地图仍拟用 MapLibre + 区域OSM/Martin + Valhalla motorcycle + Ferrostar，首区待确认；原型仅自绘道路，不代表真实算路或禁摩识别。

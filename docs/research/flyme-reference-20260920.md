## 配合本次“听发动机”方向

参考文件中的音乐卡、空调、汽车续航和车机导航只是布局样例，不是 Motuo 的功能或测量真值。用户此次要求的视觉输入是手机麦克风采到的外界声音，界面命名应相应从 `SOUND / VISUAL LAB`、合成节拍、唱片中心切换到环境声采集与声谱表现。

建议保持三个清晰状态：

1. **未开启：** 静态声谱轮廓、一个“开启麦克风”入口；不画跳动波形假装已采集。
2. **正在采集：** 小胶囊标明麦克风开启，真实音量与频谱驱动光效；大说明自动收起。
3. **不可用／中断：** 给出简短状态，图形归零或冻结并明确说明；不能悄悄回落到音乐驱动或无标签模拟。

手机麦克风采到的是混合环境声音，当前 UI 不应把音量直接命名为油门、转速或发动机负载。“听到声音变化”和“已识别发动机／起步／换挡”应保持区分；未来经实车采样验证的识别结果再作为短事件卡接入。未取得可靠车辆信号时，匀速也不能被写成小油门。

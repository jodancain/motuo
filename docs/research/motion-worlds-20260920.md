## Motuo 的体验映射

| 元素 | 动效用途 | 数据含义 |
| --- | --- | --- |
| 蓝色多层流线、漂移高亮、边缘扫光 | 日常模式的持续呼吸与流动 | 装饰氛围，无麦克风也可运动 |
| 霓虹穿梭 | 透视光廊、远近光轨与能量门，提供空间纵深 | 虚构视觉场景，不是导航地图 |
| 起步／加速／巡航／转向／减速 | 不同状态的展开、伸展、转向与收束；短状态提示、阶段亮条 | 当前来自模拟骑行脚本，未声称发动机识别 |
| 扇面声谱、声学指示 | 麦克风或显式声浪演示增强局部变化 | 关闭或无效输入时实际声学特征为零，油门／挡位保持未知 |
| 音乐播放器 | 单独播放、暂停、切曲 | 不进入动效信号链 |
| 动效预演 | 一次点击开启运动主题、模拟旅程和声浪样本 | 不请求麦克风，不播放音乐；车辆与声浪均标演示 |

常驻氛围与声学层分离，避免关麦后整页静止，也避免用装饰性频谱冒充实际听到发动机。背景可表现运动方向，速度字、模式和结束按钮位置保持稳定。GPS 缺失停止依赖车辆运动的反馈，已有明确氛围仍可继续。

## 验收层次

- HTML 控件与布局：浏览器检查开场、模式和主题切换、预演、暂停、结束、减少动态、横竖屏与声音来源。
- Canvas 合约：检查有限坐标、四主题与尺寸、无输入装饰持续、无效声源忽略旧数据、减少动态与暂停抑制声学变形／事件。
- 浏览器或 mock 结果不代表原生帧率、手机麦克风可用性、发动机分类、实车状态识别或道路使用验收。
- 记录最终实际结果在 `prototypes/motuo-v2/README.md`；保留上一轮原始验证作为历史。

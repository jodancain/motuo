# 骑行状态与音乐游戏反馈

2026-09-20 · 本轮 HTML 体验设计约定；以下状态机尚未接入原生 App，也不代表实车识别准确率已验证。

## 两种体验

- **日常模式：** 速度仪表和音乐为中心，稳定布局、节拍光环及少量转场；地图作为可选功能，不挤占仪表和控歌。
- **运动模式：** 纯游戏仪表，无地图。节拍跑道、轨道音符、能量环和状态转场提供玩乐感。音符由演示节拍自动通过，不要求驾驶时点击，也不以更快速度、更大倾斜或更猛加速兑换分数。

视觉强度与车辆负载分开。用户可以在速度稳定时享受完整动效；“运动模式”是视觉主题，不代表车辆进入某种机械模式。

## 手机能够观察什么

| 显示状态 | 后续真实识别依据 | 不应据此声称 |
|---|---|---|
| 等候 / 静止 | 连续、有效、低不确定度的近零速度；设置进入和退出滞回 | 熄火、空挡、离合已分离 |
| 起步 | 已确认静止后，连续有效速度转为移动；校准后的纵向运动可作辅助 | 起步油门百分比、发动机扭矩、具体挡位 |
| 速度稳定 | 持续有效速度窗口变化落在合理范围内；不能仅用“未检测到加速”替代 | 小油门、低负载、轻松骑行、发动机低转速 |
| 加速 / 减速 | 连续有效速度变化超过测量不确定度；手机安装校准后的纵向加速度辅助判断 | 加速必然拧油门；减速必然踩制动 |
| 左 / 右转向趋势 | 有效行进方向变化，结合固定安装后的陀螺仪与校准方向 | 精确压弯角度、附着力、弯道安全余量 |
| 感知待恢复 | GPS 缺失、过期或不确定度过大；对应数值留空 | 静止、匀速、路线补点或新事件 |

**匀速也可能是全油门。** 速度变化描述运动结果；油门是控制输入，负载又是另一量。阻力、坡度、传动和发动机状态不同，同样的速度趋势可对应不同的油门开度。仅凭手机速度、加速度和振动不能唯一还原油门或负载。本轮 HTML 常规界面显示“油门 —”，未设置独立负载栏。后续接入并校验真实 TPS/ECU 或配件信号后，才显示相应实测值；若增加负载栏，没有有效信号时仍保持未知。真实油门开度也不能直接冒充发动机负载。

Core Motion 的 `userAcceleration` 是设备运动加速度，与重力分量分开；`rotationRate` 是三轴设备旋转速率。Core Location 的 `speed` 是设备瞬时速度，负值无效。这些 API 的测量对象不是油门或发动机。来源：[Apple userAcceleration](https://developer.apple.com/documentation/coremotion/cmdevicemotion/useracceleration)、[rotationRate](https://developer.apple.com/documentation/coremotion/cmdevicemotion/rotationrate)、[speed](https://developer.apple.com/documentation/corelocation/cllocation/speed)。

## 本轮 HTML 可体验状态

本轮 HTML 自动序列为 **等候 → 起步 → 加速 → 匀速巡航 → 右转 → 减速 → 等候**，另有 GPS 缺失情景；暂无左转演示入口。每个状态来自模拟脚本，不启动手机传感器。上表中的左右转向与真实识别依据属于后续原生实现设计，不等于本轮已完成识别。

另提供 **“匀速 · 全油门示例”**：速度稳定，视觉维持饱满；如展示油门数值，必须就地标为“模拟外设 · 100%”，不能标手机识别，也不能写成真实负载。它用于验证“稳定速度不等于低油门”的产品表达。

- 起步：短暂点火式环形展开，随后回到稳定 HUD；名称表示观察到开始移动，不表示检测到发动机点火。
- 速度稳定：持续节拍、自动音符和饱满光环，不自动降成乏味或“低功率”画面。
- 加减速：光带方向和颜色渐变，特效上限固定；减速不直接标“刹车”。
- 转向：侧向光流，保留中央速度与控制按钮；不显示未经验证的角度。
- 暂停：保留全屏、冻结会话进度；结束后用更完整的动画结算。缺测时感知相关光效降级，音乐主题可以继续。

音乐节拍与车辆状态是两条独立输入。当前 HTML 点击后通过 Web Audio 播放原创合成节拍，音频与光效共享 AudioContext 的节拍时钟；它是有声音的演示，并未获取 MusicKit PCM 或分析真实歌曲的波形/节拍。音量、节拍强度、麦克风噪声均不作为转速或油门读数。

## 现有实现边界与后续验收

- `ios/Motuo/Services/RideSignalProcessor.swift` 的 `GPSSpeedTrend` 已按速度质量和连续变化计算正/负趋势；返回 `0` 同时包含未确认、变化不显著和质量不足，**不能直接映射“速度稳定”**。新增状态应区分 `unknown`、`stationary`、`launching`、`steady`、`accelerating`、`decelerating`，转向和质量另作独立维度。
- `ios/Motuo/Services/RideEngine.swift` 的 `accelerationIntensity` 是加速度模长归一化，用于视觉反馈；当前没有油门、负载或完整起步状态机。已有转向和疑似换挡属于候选事件。
- 保持原始测量、算法推断、人工确认、模拟和外设来源分别可见。起步和稳定状态需保存原始时间窗口、规则版本及置信度；缺测、暂停、恢复或更换安装方向时重置候选窗口。
- 真机测试至少覆盖：缓慢起步、走走停停、匀速高负荷、坡道、低速转向、路面震动和 GPS 中断；未知应保留未知。HTML 场景切换通过仅代表交互验收。

游戏感以音乐和视觉反馈为核心。可用完整骑行回顾、个人主题、停车后回放与持续陪伴奖励；不设计超速分、压弯排行榜、道路上的点击连击或激励反复急加速的任务。持续动画提供减弱动态选项，关键数值和结束操作始终可读。

本轮丰富仪表补充：新增三种视觉主题、面板装配/事件弹条、模拟速度曲线（GPS缺测保留断点）及未连接设备面板。频谱/波形来自本页WebAudio合成音源的AnalyserNode；它不表示获得MusicKit音频分析能力。暂停骑行冻结记录，独立播放中的音乐主题可以继续；减少动态则固定装饰层。

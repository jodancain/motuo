# Motuo 真机与实车验收

本文件是待执行的验收记录模板。模拟器、API 测试和签名构建不能替代以下实测；尚未记录任何实际骑行或真实 Watch 震动结果。

每次记录：日期、应用构建号、手机/Watch 型号和系统、车辆年份/ABS/轮胎/改装、支架与校准版本、头盔耳机、环境温度、导航方式、实际授权状态。不在共享仓库提交个人路线、车牌或设备令牌。

| 场景 | 观察与通过条件 | 当前记录 |
|---|---|---|
| 60 分钟连续骑行 | 导航、MusicKit、记录和 HUD 同开；正常温度目标 60 fps，热降级 30 fps；记录不依赖画面刷新 | 待实车 |
| GPS 隧道/失锁/拒绝权限 | 速度未知、路线有缺口；不补零速、虚构轨迹或跨缺口距离 | 待真机 |
| 锁屏/切后台 | 分别检查 GPS 和 IMU 数据连续性、权限变化与系统暂停；不把前台采样率当后台保证 | 待真机 |
| 来电/耳机断开 | 播放与音频中断按系统权限处理；耳机断开暂停，恢复行为明确 | 待真机 |
| 离线/存储不足/强杀 | 已确认分块可恢复；写入失败明显告知并停止新增记录；缺测明确标记 | 强杀仅模拟器已验，其他待真机 |
| Watch 活动/垂腕/锁屏/断连 | 实际触感逐类验；过期不补发，冷却去重生效 | 待真实手表 |
| 安装校准 | 熄火扶正采样；移动拒绝、方向不明确拒绝、重装须新版本 | 算法与入口本机可测，车辆坐标待实车 |
| 倾斜 | 仅方向与强度；独立动态参考集 MAE ≤5°并报告覆盖率/高误差片段之前，数值倾角保持禁用 | 未启用数值倾角 |
| 实际配件 | 指定硬件/固件/驱动验证 GATT/Bonjour、单位、断连、过期值 | 仅协议与软件模拟器 |
| 高德摩托 | 商业权限、车型/车牌/排量、禁限行和实地播报验证；未授权时明确外部导航 | 商业能力未启用 |
| 维修手册 | 车型适用、原页/表格单位、警示和引用跳页；问题无证据时明确缺证据 | 见独立手册验收文件 |

驾驶过程中仅操作稳定的大按钮。维修问答、事件纠正、校准与个人模型更新在停车后完成。初版不会把异常振动、疑似换挡或统计阈值直接当作零件损坏或真实挡位。

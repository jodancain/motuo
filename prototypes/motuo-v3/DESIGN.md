# Motuo v3 · 骑行即漫画 MV —— 设计文档

> 一句话：**整块屏幕就是一格正在连载的漫画，你的车是主角，速度是这一格的标题。**

v2 的问题是“卡片仪表 + 背景特效”：信息卡挤满屏幕，车很小，特效只是装饰。v3 从零开始：没有卡片，没有面板栏，只有一个活的场景、一辆大车、一个巨型数字，以及页角的小字注释。

## 1. 艺术方向

参考：《蜘蛛侠：纵横宇宙》的印刷语言 × 《Hi-Fi Rush》的节拍感 × 赛车游戏的出发与结算。统一成一句规则：**一切都是“印出来的漫画”。**

| 元素 | 规则 |
|---|---|
| 纸张 | 暖白纸 `#f3ead6`，全屏 6px 纸边 + 3px 墨线框 = 一格分镜。高档位叠一层静态纸纹（multiply，不闪）。 |
| 墨线 | 全部前景物体（楼、护栏、路缘、车）有深墨描边 `#0b0a12`，粗细 2–4px。 |
| 色彩 | 每个世界 1 个主色 + 1 个撞色 + 墨色 + 纸色；平涂，不用写实渐变。天空可用分段渐变 + 网点过渡。 |
| 网点 Ben-Day | 天空近地平线、建筑暗面、车身暗部（着色器）、分镜背景、暂停泛黄画面。 |
| CMY 套印错位 | 远景/中景剪影绘制青、品红两道偏移残影；速度巨字有固定套印影。节拍时可“套印抖动”，计入闪光限流。低档关闭。 |
| 一拍二 | 车（GLB 漫画渲染、姿态位移）以 12fps 步进；背景视差、速度线以 60fps 平滑；特效粒子 30fps。 |
| 手绘线 | 速度线、集中线是变宽的楔形，带随机抖动，不是规则几何。 |
| 字体 | 速度：MotuoNum（Orbitron 等宽数字，避免宽度跳动）；英文拟声与标题：MotuoDisplay（Russo One）；中文拟声与旁白：MotuoHan（得意黑）。均复制自 v2 的 OFL 子集；v3 新文案限定在子集内，测试会解析 woff2 cmap 校验。 |

## 3. 状态与画面

| 状态 | 画面 |
|---|---|
| 待机 `idle` | 场景缓慢巡游（装饰），车停在路中，速度显示 `0`（灰，非读数）；点车轰油门、上滑抬头、长按烧胎蓄力、左右拖拽换角度/甩尾。 |
| 倒计时 `countdown` | READY → 3 → 2 → 1 → GO!!，每拍 0.8s；车原地烧胎（后轮狂转、烟团），集中线，节拍 UI 音。GO 时冲击帧（限流）、车冲出、世界开始滚动。可点“跳过 ›”。 |
| 骑行 `riding` | 世界按读数滚动；纵向加速度 → 速度线密度 + 画面倾斜（≤4°）；声浪 → 楼群均衡器 + 车身震动。事件触发分镜 cut-in。 |
| 分镜 cut-in | 0.6–1.2s。画面裂成 2–4 个斜切格：后轮烟、排气火焰、刹车盘火花、车头光、仪表格（速度原地带进分镜）。首帧为冲击帧（墨白反相，计入限流）。速度层永远在分镜之上。 |
| 关卡切换 | 翻页：旧画面快照被翻起（3D 页角 + 阴影），露出新世界。速度层在翻页之上。 |
| 暂停 `paused` | 漫画定格：世界与车冻结，画面泛黄、网点加粗、格子缩进成一页上的一格；右下 “TO BE CONTINUED →” 箭头滑入。速度显示 `—`（记录暂停，与原生一致）。继续：翻页恢复 + “GO!”。 |
| 结束 `comic` | “FIN” 印章 → 生成「今日骑行漫画」：一页 4–6 格，逐格砸入；每格是当时状态的场景重绘 + 车姿态 + 拟声字 + 真实数值注释。可保存 PNG。 |

## 4. 动效节奏

- 主时钟：单 rAF（`core/loop.js`），所有渲染任务共用；页面隐藏即停（rAF、音频挂起、演示时间冻结）。
- 车：12fps；姿态弹簧照常计算，只在步进时刻采样。
- 背景/速度线：60fps；滚动速度向读数目标做视觉缓动（只影响滚动，不影响数字）。
- 速度数字：新读数到达时**整体替换**，伴随 120ms 盖章缩放（1.1→1，始终完整可见）；不滚轮、不插值。
- 冲击帧/套印闪：统一闪光限流器（任意 1s ≤ 2 次，WCAG 2.3.1 上限 3 次）。拒绝时降级为无闪版本。
- cut-in 间隔 ≥ 1.4s，排队最多 1 个，过期丢弃。
- 减少动态（系统偏好或手动）：无滚动/倾斜/震动/闪光；cut-in 换成静态角标字幕；倒计时只换字；暂停为静态泛黄；漫画页一次性显示。

## 5. 性能预算

| 档位 | DPR 上限 | 套印/纸纹 | 粒子 | 车渲染 |
|---|---|---|---|---|
| 高 high | 2 | 开 | 100% | 12fps，DPR 1.5 |
| 中 mid | 1.5 | 套印开、纸纹关 | 60% | 12fps，DPR 1.25 |
| 低 low | 1 | 全关 | 30% | 12fps（下降为 8fps），DPR 1 |

- 自动降级：帧间隔 EMA > 22ms 持续 1.5s 降一档；< 17.5ms 持续 6s 升一档（滞回）。设置可固定档位。原生 `thermal` 提示强制不高于中档。
- 目标：中档手机 60fps 背景；单帧 JS < 6ms；GLB 首次解析一次，之后只改 uniform。
- 桌面 headless 数据只作参考，不代表手机。

## 6. 数据真实性边界

- 速度数字 = 最新一条有效读数取整（`Math.round`）；无读数 `—`；惯导短时估计前缀 `≈`。**不插值、不平滑后显示**。
- 不显示数字 RPM、挡位、油门、倾角。车身姿态（抬头/点头/倾斜）全部是装饰，不输出数值。
- 加速度只由连续同源速度读数差分（复制 v2 `drive-signals.js`）；未知即关闭相关效果。
- 声浪只在麦克风显式授权或显式“声浪 DEMO”时驱动楼群与震动；麦克风本机分析，不录音、不上传。
- 演示驾驶：1Hz 离散读数帧，全程标 DEMO；里程由读数积分并标 DEMO。
- 游戏分 / 连击：标明“游戏分 · 非驾驶评价”。
- 漫画注释：每个数字都来自记录（读数、差分加速度、计时、积分里程、游戏分），测试校验。
- 数据源标签始终在页角：`DEMO 模拟读数` / `GPS 实测` / `惯导估计` / `等待有效定位`。

## 7. 安全与可读性

- 骑行中速度层 z 序高于分镜、翻页、冲击帧、拟声字；测试与录屏逐帧检查最长不可读时段（目标 0ms，上限 150ms）。
- 闪光：任意 1s ≤ 2 次。
- 骑行中车的手势停用（防误触）；只保留暂停/结束/跳过。

## 8. 与原生的接口

`native-adapter.js` 接收与 `ios/Motuo/Cockpit/native-runtime.js` 相同的 `MotuoNativeReceive(state)` 快照，映射为 v3 的读数帧；本轮不改原生工程。见 README「接入原生」。

## 9. 速度突破剧场（2026-10-21）

用户反馈“速度突破太单一”。原来每个里程碑都是“突破 30 KM/H + ZOOM!”的同一格 cut-in，现在改成 1.3–2.4 秒的迷你漫画剧场，演出由 **剧目 × 世界反应 × 等级 × 镜头 × 数字变形** 组合而成。代码：`core/milestone-director.js`（读数 → 计划，纯逻辑）、`render/milestone-player.js`（计划 → 画面，接单 rAF 与统一闪光限流）、`render/milestone-acts/*.js`（剧目）、`data/speed-comparisons.js`（对比表）、`core/milestone-gallery.js`（画廊）。

### 阶梯

20 / 30 / 40 / 50 / 60 / 80 / 100 / 120 / 140 / 160 / 180 / 200 km/h。等级：<40 小（1.3s）、40–59 中（1.5s）、60–99 大（1.8s，叠加一个镜头花活）、100 大事件（2.2s，三幕串联）、≥120 传说（2.4s）；回归 0.9s。粒子数 = 性能档粒子系数 × 等级系数；低档自动减量。

### 防刷与真实性

- 只用真实读数：`source==='gps'` 才计；惯导估速 ≈、未知读数不触发，也不作为下一条的起点。
- 滞回：跌回阈值 −8 km/h 才重新武装；冷却：同一阈值 20s 内再次突破不演出，20s 后演“回归”简化版。
- 一条读数跨过多个阈值只庆祝最高；演出中再突破最多排队 1 个（取更高者），当前演出结束后 1.5s 内没开始就丢弃。
- 剧目带种子随机（演示固定种子 20261021，可复现）；连续两次不同；一次骑行内先用完剧目池再重复；世界偏好加权 ×3。
- 今日新高：每次骑行最多一次，阈值 ≥60 且高于“开骑前的今日最高”。历史存 `localStorage['motuo.v3.milestone-history']`（`version: 1`，保留 30 天），只有非演示的真实 GPS 读数会写入；演示、画廊、估速都不写。
- 剧场进行中，分镜 cut-in 让位（`director.hold`），结束后再播排队的那一个。
- 闪光：每次演出每种闪光最多一次、合计 ≤2，经统一限流器（任意 1s ≤2）。减少动态：只画一张静态卡片（主剧目定格 + 标签）1.6s，不动画、不闪、不动镜头。页面隐藏：取消当前与排队演出，返回不补播。

### 漫画与画廊

- 骑行漫画里，最精彩的一次突破（今日新高 > 等级 > 阈值）占一格，画该剧目的定格画面；注释为“突破 XX KM/H · 当时读数 · 剧目名”，数值取自记录。
- `?gallery=milestones` 或 设置 →“突破画廊”：上一个 / 重播 / 下一个 / 自动轮播（每次换世界）/ 世界 / 等级；全程标“预览 · 非骑行数据 · 不写入任何纪录”。

### 视觉返工（10/21 审核后）

- **舞台**：剧目使用整屏减去速度巨字保留区（横屏为速度区左侧整列 + 速度区下方副台；竖屏为速度区下方整片），速度区仍挖空（evenodd）、速度 DOM 永远最上层。关键道具横屏 ≥ 屏高 50%（纸墙约 62%），竖屏 ≥ 30%（速度巨字占上部，下方空间决定上限）。
- **分区**：标签芯片 / 主文字 / 徽章 / 注释各有区域；竖屏主文字被限定在标签之下、不压徽章。
- **一次一个主文字**：剧目通过 `e.say()` 申请主文字，播放器每帧只画优先级最高（同级取后开始）的一条；大事件横幅优先级最高，只在开场与收尾出现，中间让位给三幕剧目的主文字。叠加的镜头花活不写字。
- **四拍**：起（0–26%，看清道具）→ 冲突（26–46%）→ 爆点（46–60%，冲击帧 + 拟声，冲击帧走统一闪光限流）→ 余韵（60–100%，碎片/彩纸/冰片飘落）。
- **车参与**：每个剧目导出 `bike(p, e)` 姿态增量——撞墙/冲线/超越类先后退让出道具、再冲刺穿过、弹簧回位；盖章时被压扁震动；成就/烟花时抬头；子弹时间冻结再猛冲；甩镜切到 3/4 斜侧机位；冲刺时叠画车身残影。姿态仍按 12fps 步进渲染，减少动态时不动车。
- **动物**：11 种（跑者、大象、灰熊、长颈鹿、灰狗、袋鼠、鸵鸟、赛马、野兔、叉角羚、猎豹）改为平涂 + 墨线 + 3 帧步进奔跑，有特征（象鼻象牙、长颈鹿斑块与角、袋鼠尾巴、鸵鸟粉颈、野兔长耳等）；对照图见录制产物 `frames/compare-silhouettes.png`。
- **画廊**：底部细条“‹ 名称 › 更多 退出”，默认收起；“更多”展开重播 / 自动轮播 / 世界 / 等级。
- **加载**：GLB 未就绪时显示漫画风 LOADING 卡片，不先闪一帧矢量回退车；8s 仍未就绪才显示矢量车，加载失败立即回退。

## 10. 车辆状态交互（2026-10-23）

数据：只用车辆状态估计器的推断（演示为模拟），低置信度按 `confidenceGain` 弱化；静止不出任何加速 / 刹车效果；不显示倾角、RPM 数字。车向画面右侧行驶，所以**左弯 = 画面逆时针倾斜、路与速度线向上弯、内侧集中线在上方**；右弯相反。

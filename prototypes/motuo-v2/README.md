# Motuo · Ride the Frequency

先评审 HTML，再修改原生 App。本目录是独立 HTML，不安装依赖、不连接 NAS。双击也能看界面；实际麦克风应使用 HTTPS 或当前电脑的 localhost。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/motuo-v2
```

预览：`http://127.0.0.1:8765/`。服务仅绑定当前电脑；手机访问普通局域网 HTTP 不满足麦克风安全上下文要求。

## 当前体验：外界声浪驱动

- **日常模式：** 大速度仪表、外围声学光环与独立音乐控制。地图仍可切换为虚构示意导航。
- **运动模式：** 无地图，三种主题（霓虹赛道 / 频谱星环 / 极光矩阵）、错峰装配、限时状态弹条、扫描环、光轨、粒子，以及模拟速度历史/事件和未连接设备面板。
- **大卡片仅出现2.8秒**，随后hidden；采用绝对定位，不占用长期布局。默认展示一次声浪介绍，启用输入/显式演示时短暂反馈；切歌曲不会唤起大卡。Flyme参考采用大场景、窄状态带、局部浮层、白灰文字层级和固定底部操作，见 [参考解析](../../docs/research/flyme-reference-20260920.md)。没有复制其图片、字体或皮肤素材。
- 普通启动 → 开始骑行隐藏顶部品牌栏和导航 → 暂停保持全屏 → 结束复盘恢复。横竖屏跟随窗口，不强制旋转；这是页面沉浸，原生系统栏另行验收。
- 点击右上角麦克风图标打开「声浪」。**默认关闭；点击启用才请求权限。** `getUserMedia → AnalyserNode` 在本机分析RMS、频谱和波形，驱动外围光环、粒子、光带和能量条。输入音频不连接扬声器，不录文件、不保存原音/特征、不上传。
- 权限请求可取消，拒绝/缺设备/不可用有明确提示；取消、输入结束、音频上下文中断、切后台、离开驾驶舱或结束骑行均停止相关采集。返回不自动开启；迟到的授权结果立即停止全部tracks。
- **声浪演示需单独点击**；为无声的合成特征预览，明确显示DEMO，不获取麦克风、不冒充发动机声音。真实模式无有效输入时频谱、强度归零，数值为`—`，仅保留待机装饰光场。
- 音乐仍可播放/暂停/切换三套原创合成试听。音乐调度与声音输入/视觉时钟分开，播放音乐不会产生声浪数据；外放音乐被麦克风物理拾入时仍属于外界混合声。
- 保留起步→加速→巡航→右转→减速→停稳的模拟旅程，以及GPS缺测、NAS断连等演示。匀速全油门示例明确标为`100% / 模拟 TPS 输入 · 非手机推断`，默认油门与挡位未知；声音大小也不替代油门。
- 减少动态选项停止装饰动画和声音形变，保留文字与有效输入状态。暂停骑行冻结记录，仍可独立停止麦克风或音乐。

## 测量与交付边界

RMS电平显示dBFS，三频段百分比是归一化频谱值，均不是环境声压、转速或负载。当前只接收混合声音，**未实现发动机/风噪/人声分类，未实现音频转速或油门识别**。实际输入可能是系统默认/蓝牙设备，启用后显示设备名；手机内置话筒需真机核验。设计见 [声音输入约定](../../docs/research/engine-audio-input-20260920.md)。

速度、车辆运动状态、路线和设备仍为演示，不读取真实GPS或IMU，不接真实Watch/BLE/NAS/AI/MusicKit。档案只保留当前页面最后一次演示，刷新清空。原生TestFlight **0.1.0 (1)** 保持原状，本次未修改SwiftUI或部署NAS。

正式地图仍拟用 MapLibre + 区域OSM/Martin + Valhalla motorcycle + Ferrostar，首区待确认；原型仅自绘道路，不代表真实算路或禁摩识别。
